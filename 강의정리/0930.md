### 01-01 프롬프트는 블록으로 조립한다. 
- 블록은 서로 독립적이라 하나씩 넣고 빼며 효과를 볼 수 있음 
- 블록화된 프롬프트와 지시문; 길이, 형식이 흔들리지 않음; 없는내용 기록 방지 등
- `System` : 고정된 지시문, 지시 위계에서 우선하도록 모델이 학습; 프롬프트 캐시
- `형식의 강제` : 형식은 부탁이 아니라, 스키마로 지정

#### 대충 쓰지 않은, 블록을 채운 지시문(v1)
```python
BLOCKS = {
    '페르소나': '당신은 경력 10년의 기술 문서 편집자입니다.',
    '지시':     '회의록에서 결정 사항과 후속 조치를 정리하세요.',
    '문맥':     '회의에 빠진 사람이 5분 안에 상황을 파악해야 합니다.',
    '청중':     '읽는 사람은 새로 합류한 개발자입니다.',
    '형식':     '결정 사항은 불릿 3~5개로, 후속 조치는 "담당자 | 할 일 | 기한" 표로 쓰세요.',
    '어투':     '간결하고 중립적으로 쓰세요. "합니다"체를 지양하고, 개조식으로',
    '규칙':     '회의록에 없는 내용은 쓰지 마세요.',
}

def make_system(skip=None):
    """블록을 한 줄씩 이어 붙인다. skip에 적은 블록은 뺀다."""
    return '\n'.join(f'[{name}] {text}' for name, text in BLOCKS.items() if name != skip)

V1_SYSTEM = make_system()
V1_USER = f'<회의록>{MEETING}</회의록>'
```

#### 감이 아니라 숫자로 - 규칙 준수율 
- 지켜야 할 규칙을 Boolean으로 검사하는 함수를 생성

```python
import pandas as pd
def check(answer):
    """규칙마다 지켰으면 True, 아니면 False"""
    return {
        '담당자 3명 모두':  all(name in answer for name in ['김민수', '이지영', '박준호']),
        '기한 3개 모두':    all(day in answer for day in ['10/2', '10/6', '10/10']),
        '표 사용':          '|' in answer,
        '600자 이내':       len(answer) <= 600,
    }

check(ask(V1_SYSTEM, V1_USER))


VERSIONS = {
    'v0 대충':   (V0_SYSTEM, V0_USER),
    'v1 블록':   (V1_SYSTEM, V1_USER),
}
N = 5   # 버전마다 몇 번 돌릴지

rows = []
for version, (system, user) in VERSIONS.items():
    for i in range(N):
        result = check(ask(system, user))
        result['버전'] = version # check의 결과에  버전이라는 프로퍼티를 추가 
        rows.append(result)

df = pd.DataFrame(rows)
df.groupby('버전').mean().round(2)   # True=1, False=0 이라서 평균이 곧 준수율
```

## 02 프롬프트 엔지니어링(2) - 예시와 추론
- 설명 대신 보여주고, 답하기 전에 생각하게 하기 
- 제로샷 : 예시 없이 지시만
- 원샷 : 예시 1개로 답의 모양을 제시 
- 퓨샷 : 여러 개, 경계 사례로 기준을 제시 
    - Brown et ai(2020); 가중치를 고치지 않고 프롬프트의 예시만으로 새 과제를 수행
    - (1) User / Assistant 에 쌍으로 넣기 
        ```python
        {'role': 'user', 'content': '  색이 달라요'},
        {'role': 'assistant', 'content': ' 제품'},      #   예시 1
        {'content': '  반품하고 싶어요'},
        {'role': 'assistant', 'content': ' 환불'}        #   예시 2
        ```
    - (2) System 안에 넣기; 장점은 캐시로 활용하여 비용을 절감할 수 있다는 점에 있음
        ```python
        SYSTEM = """문의를 두 유형으로 분류하세요.
        <examples>
            <example>< 문의>  색이 달라요</ 문의>< 유형> 제품</ 유형></example>
            <example>< 문의>  반품하고 싶어요</ 문의>< 유형> 환불</ 유형></example>
        <examples>"""
        ```

- 4가지 단계의 시스템 프롬프트 : CLASSIFY · EXTRACT · REPLY_RULES · CHECK_RULES
    - 01 CLASSIFY(분류)
        ```python
        TESTS = [   # (문의, 정답) — 평가셋
            ('택배가 아직 안 왔어요', '배송'),
            ('사이즈가 작아서 교환하고 싶어요', '환불'),
            ('주문 취소 가능한가요?', '환불'),
            ('이 제품 세탁기에 돌려도 되나요?', '제품'),
            ('포인트가 적립이 안 됐어요', '기타'),
            ('배송지 주소를 바꾸고 싶어요', '배송'),
            ('색상이 사진과 달라서 반품할게요', '환불'),
            ('쿠폰이 적용이 안 돼요', '기타'),
            ('전원이 안 켜져요', '제품'),
            ('교환 신청했는데 언제 오나요?', '환불'),
        ]

        def classify(system, question, examples=None):
            """문의 하나를 분류한다. examples가 있으면 user/assistant 대화 쌍으로 앞에 넣는다"""
            messages = [{'role': 'system', 'content': system}]
            for q, a in (examples or []):
                messages.append({'role': 'user', 'content': q})
                messages.append({'role': 'assistant', 'content': a})
            messages.append({'role': 'user', 'content': question})
            r = client.chat.completions.create(model=MODEL, messages=messages)
            return r.choices[0].message.content.strip().strip('.')

        def score(system, examples=None):
            """평가셋 전체를 분류하고 정확도를 돌려준다. 문항마다 ✅/❌ 로 전부 출력"""
            preds = [classify(system, q, examples) for q, _ in TESTS]
            for (q, answer), pred in zip(TESTS, preds):
                mark = '✅' if pred == answer else '❌'
                print(f'  {mark} {q}  정답={answer}  예측={pred}')
            acc = sum(p == a for p, (_, a) in zip(preds, TESTS)) / len(TESTS)
            print(f'정확도 {acc:.0%}')
            return acc, preds
        ```
