# 이것이 컴퓨터 과학이다 - 정리 규칙

유튜브 강의와 저서 「이것이 컴퓨터 과학이다」를 기반으로 md 파일을 정리한다.
작업은 Top-down 방식으로 진행한다: 목차 → Chapter 파일 → 소제목/부제 → 본문.

## 파일 구조

- `Chapters.md` : 전체 목차(index). 각 CHAPTER 파일로 링크한다.
- `Chapter-NN.md` : CHAPTER 별 파일. NN은 두 자리 번호(01, 02, …).
- 파일 간 링크는 상대 경로(`Chapter-01.md`)를 사용한다.

## Chapter-NN.md 작성 형식

```markdown
[← Chapters](./Chapters.md)

# CHAPTER NN 제목

## index
- [1 소제목](#anchor)        # 같은 파일 내 ## 소제목으로 이동하는 링크
  - [(1) 부제](#1-부제)      # 해당 ### 부제로 이동하는 링크 (2칸 들여쓰기)

## 1 소제목
### (1) 부제
_text

### (2) 부제
_text

## 2 소제목
...
```

- 최상단 `[← Chapters](./Chapters.md)` : 목차(Chapters.md)로 돌아가는 링크. 모든 Chapter 파일에 둔다.
- `#` : CHAPTER 제목 (파일당 1개)
- `## index` : 해당 CHAPTER의 ## 소제목 목록. 각 항목은 해당 소제목으로 연결한다.
  - 각 ## 소제목 아래에 그 소제목의 `### (n)` 부제를 2칸 들여쓴 하위 항목으로 연결한다.
  - NOTE/TIP 항목은 `### 부제`가 없으므로 하위 항목 없이 한 줄로 둔다.
- `## 소제목` : 책의 소제목. 번호(num)를 붙인다 (`## 1 원리를 모르는 …`).
- `### 부제` : 소제목 아래의 부제. 순번 `(1)`, `(2)`, `(3)`…을 붙인다.
- 순번(`(n)`)은 `##`마다 1부터 다시 시작한다.
- `### (n) 부제` 하단은 비워 둔다. 블릿이나 본문은 학습하며 채워 넣는다.

## 번호와 명칭 규칙

- 책의 `[추가 학습 NOTE]`, `[기술 면접 TIP]` 항목은 번호 없이 `## [항목명] 제목` 형식으로 쓴다.
- 이 항목들은 `## index`에도 포함한다. index의 대괄호는 `\[`, `\]`로 이스케이프한다.
- 책의 `__` 항목은 `### (n) 부제`로 변환한다.

## 작업 순서 (Top-down)

1. `Chapters.md`에 CHAPTER 목록과 링크를 먼저 만든다.
2. 각 `Chapter-NN.md`에 제목, `## index`, `## 소제목`, `### (n) 부제`, `_text` 뼈대를 만든다.
3. 뼈대의 링크와 번호가 맞는지 확인한 뒤 `_text`를 실제 본문으로 채운다.

## 작성 어체

- 개조식으로 작성한다. `~이다`, `~한다`, `~된다` 같은 서술형 종결을 지양한다.
- 명사·동사 중심으로 짧게 끊는다. 예: `- 가상 메모리: 물리 메모리보다 큰 주소 공간을 제공` (O), `- 가상 메모리는 물리 메모리보다 큰 주소 공간을 제공한다` (X)
- 필요하면 `→`, `/`, `:`로 관계를 표시한다.

## 주의

- 원서나 강의 자료를 그대로 옮겨 쓰지 않는다. 요약하고 설명을 덧붙이는 방식으로 정리한다.
- 파일을 다시 만들 때 기존 본문을 덮어쓰지 않도록 주의한다.
