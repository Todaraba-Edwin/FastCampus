# 이것이 컴퓨터 과학이다 - Chapters

> 컴퓨터 과학이란 연산, 정보, 자동화에 대한 학문이다
>
> 컴퓨터 과학이란 프로그램 작동의 근거를 설명하는 학문이라고도 정의한다

- 연산: 문제를 단계별 절차(알고리즘)로 풀어 결과 도출
- 정보: 데이터를 0과 1로 표현·저장·전달
- 자동화: 반복 작업을 프로그램으로 대신 수행
- 하드웨어: CPU, 메모리, 저장장치가 명령어를 실행
- 소프트웨어: 운영체제가 자원을 관리하고 응용 프로그램이 이를 활용
- 자료구조·알고리즘: 데이터 저장 방식과 처리 효율 결정
- 네트워크: 떨어진 컴퓨터 간 데이터 교환 규칙 제공
- 데이터베이스: 대량 데이터의 체계적 저장·검색·무결성 유지
