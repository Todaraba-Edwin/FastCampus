### 첫째, 왜 파이썬인가
#### (1) 쉬운 문법
- 영어에 가까운 간결한 문법
- 초보자 진입 장벽 낮음
- 누구나 빠르게 시작 가능

#### (2) 활용 분야의 다양성
- 웹 개발
- 데이터 분석
- 인공지능
- 자동화
- 배운 내용 곧바로 실무 적용 가능

### 둘째, 파이썬이란?
#### (1) 역사 및 개발
- 귀도 반 로섬(Guido van Rossum)의 취미로 시작된 프로그래밍 언어
- Python v1.0: 1991년 발표
- Python v2.0: 2000년 (많은 산업체 도입)
- Python v3.0: 2008년 (구조적 개선, 현재 표준)

#### (2) 현재의 위상
- 전 세계 가장 인기 있는 프로그래밍 언어
- 데이터과학, 인공지능, 웹개발 분야의 표준 언어
- 초보자부터 전문가까지 널리 사용
- 지속적인 커뮤니티 발전과 라이브러리 확충

### 셋째, 프로그래밍 언어의 종류
#### (1) 인터프리터 언어 vs 컴파일 언어
- **인터프리터 언어 (Python)**
  - 코드를 한 줄씩 실행
  - 개발 속도 빠름, 실행 속도 느림
  - 플랫폼 독립적

- **컴파일 언어 (C, C++)**
  - 코드를 먼저 기계어로 변환(컴파일)
  - 컴파일 시간 필요, 실행 속도 빠름
  - 플랫폼 의존적

#### (2) 저수준 언어와 고수준 언어
- **저수준 언어**
  - 기계어, 어셈블리
  - CPU가 직접 이해
  - 하드웨어에 가장 가까움
  - 성능 최적화 가능

- **고수준 언어**
  - Python, Java, C++, JavaScript, C# 등
  - 인간이 이해하기 쉬운 문법
  - 개발 생산성 향상
  - 유지보수 용이

### 넷째, 파이썬으로 할 수 없는 일
#### (1) 시스템 프로그래밍
- 운영체제(OS) 커널 개발
- 디바이스 드라이버 개발
- 임베디드 시스템 프로그래밍
- 이유: 하드웨어 제어 필요 → C, C++, Assembly 사용

#### (2) 모바일 프로그래밍
- iOS 앱 개발 (Objective-C, Swift)
- Android 네이티브 앱 (Java, Kotlin)
- 이유: OS별 고성능 최적화 필요
- 참고: Python은 크로스플랫폼 라이브러리(Kivy 등) 있지만 제한적
