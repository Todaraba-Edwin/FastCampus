# Claude 가이드

## 사용법

### 새로운 강의 생성
- 파일명 제공 → `#` 제목, `## index` 자동 생성
- **파일 형식**: 파일명 확장자로 생성 형식 결정
  - `.md` 확장자 명시 → Markdown 파일 생성
  - `.ipynb` 확장자 명시 → Jupyter Notebook 파일 생성
  - 확장자 없음 → 기본값: Markdown

## 문서 구조

### 강의 문서 구성
- `# 제목`: 강의 제목
- `## index`: 목차 + 링크
- `### 첫째, 소제목`: 섹션 제목
- `#### (1), (2), (3)...`: 소제목마다 번호 리셋

### 예시
```markdown
# 01강. 파이썬이란 무엇인가?

## index

- [첫째, 파이썬의 정의](#첫째-파이썬의-정의)
  - [(1) 파이썬이란?](#1-파이썬이란)
  - [(2) 파이썬의 특징](#2-파이썬의-특징)
- [둘째, 파이썬의 역사](#둘째-파이썬의-역사)
  - [(1) 개발 배경](#1-개발-배경)
  - [(2) 버전 변화](#2-버전-변화)

### 첫째, 파이썬의 정의
#### (1) 파이썬이란?
#### (2) 파이썬의 특징

### 둘째, 파이썬의 역사
#### (1) 개발 배경
#### (2) 버전 변화
```

## 글쓰기 스타일

### 기본 원칙
- 종결어미: '합니다', '있습니다' 제거 → 개조식
- 말머리기호(bullet) 기반 간결한 표현
- 한 줄 한 개념

### 변환 예시

#### ❌ 금지
```
(1) 쉬운 문법
파이썬은 영어에 가까운 간결한 문법으로 초보자가 배우기 쉽습니다. 프로그래밍의 진입 장벽을 낮춰 누구나 빠르게 시작할 수 있습니다.
```

#### ✅ 권장
```
(1) 쉬운 문법
- 영어에 가까운 간결한 문법
- 초보자 진입 장벽 낮음
- 누구나 빠르게 시작 가능
```

## 주의사항
- `#### ` 번호 (1)부터 시작, 각 `##` 섹션마다 리셋
- 상단: `[← 돌아가기](00.index.md)` 링크 유지
- `## index`: `### ####` 마크다운 링크로 연결
  - 형식: `[텍스트](#헤더-텍스트)`
  - 앵커: 소문자, 띄어쓰기 → `-`
