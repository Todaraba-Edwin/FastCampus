## 첫째, AI 에이전트 구축의 핵심; 목표에 알맞는 에이전트 패턴과 컨텍스트 엔지니어링

### (1) 워크플로우와 에이전트; 복잡성과 자율성을 기반으로
- 워크플로우: 사전 정의된 단계와 조건으로 구성, 복잡도 낮음, 자율성 없음
- 에이전트: 실시간 의사결정과 적응, 높은 자율성, 복잡한 문제 해결 가능
- 문제의 복잡도와 요구되는 자율성 정도에 따라 워크플로우 또는 에이전트 선택으로 비용-효율성 최적화

### (2) 에이전트 패턴의 선택
- 목표와 문제 특성에 따라 ReAct(Reasoning + Acting), Tool Use, Planning 등 최적의 패턴을 선택
- 각 패턴은 다양한 작업 유형(의사결정, 정보검색, 문제해결)에 특화된 특성 보유
- 잘못된 패턴 선택은 성능 저하, 비용 증가, 부정확한 결과 초래

### (3) 컨텍스트 엔지니어링의 중요성
- 프롬프트 설계, 시스템 메시지, Few-shot 예제, 입력 구조화로 에이전트 성능과 정확도 향상
- 같은 패턴이어도 컨텍스트 품질에 따라 결과의 신뢰성과 일관성이 크게 달라짐
- 명확한 역할 정의, 구체적 지시사항, 제약조건 명시로 에이전트 동작 정확화

### (4) 목표-패턴-컨텍스트 매핑
- 사용 목표(자동화, 의사결정, 정보검색, 고객 응답)에 맞는 에이전트 패턴 결정
- 선택된 패턴에 최적화된 컨텍스트 엔지니어링 적용
- 이 세 요소의 조화가 에이전트의 효율성, 신뢰성, 확장성을 결정

## 둘째, AI 에이전트; 레벨별 프레임워크

### (1) No-code (n8n)
- 코드 작성 없이 UI 기반 블록을 드래그 앤 드롭으로 워크플로우 구성
- 비개발자도 사용 가능하며, 빠른 프로토타입 개발과 자동화 구축이 용이
- **n8n 사례**
  - n8n에서 이메일 트리거로 Slack 알림 자동 전송
  - n8n으로 웹 폼 제출 시 Google Sheets에 데이터 자동 기록
  - n8n을 통한 CRM과 소셜 미디어 계정 자동 동기화
  - n8n으로 정기적인 데이터 수집 및 리포팅 자동화

### (2) Low-code (SDK)
- 제공되는 SDK를 활용하여 최소한의 코드로 에이전트 구현
- OpenAI Agents SDK, Claude Agents SDK, LangChain 등을 통해 빠르게 프로토타입 개발
- **사례**
  - OpenAI Agents SDK: 함수 호출(Function Calling) 기반으로 API 자동 통합, 도구 자동 실행
  - Claude Agents SDK: Tool use를 활용한 에이전트 구축, 다양한 외부 서비스 연동
  - LangChain: 간단한 RAG 시스템, 체인 구성, 메모리 관리 등 빠른 구현

### (3) Raw (Low Level)-code (LangGraph)
- 복잡한 에이전트 로직을 직접 작성하며, 완전한 제어와 최적화 가능
- 상태 관리, 복잡한 분기 로직, 커스텀 메모리 등을 자유롭게 구현
- **LangGraph 사례**
  - LangGraph로 다단계 의사결정이 필요한 에이전트 시스템 구축
  - LangGraph의 상태 그래프로 멀티 에이전트 간의 복잡한 상호작용 관리
  - LangGraph 노드 구성으로 동적 프롬프트 최적화 및 실시간 피드백 루프 구현
  - LangGraph를 활용한 프로덕션 레벨의 신뢰성 있는 에이전트 시스템 개발
