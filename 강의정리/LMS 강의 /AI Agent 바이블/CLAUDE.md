## 파일별 규칙

### 1️⃣ 최상위 Index (AI Agent 바이블.md)
- 강의 제목과 간단한 설명
- 강의 저장소 링크 (테이블 형식)
- 각 Part로의 링크
- 학습 로드맵
- **마지막 업데이트 날짜**

### 2️⃣ Part Index (PART-NUM-README.md)
- **상위 링크** (최상단)
  ```markdown
  [← AI Agent 바이블](../AI Agent 바이블.md)
  ```
- Part 제목
- **Index 섹션만 포함**
  ```markdown
  # Part N. [제목]
  
  ## 📑 Index
  - [Chap-01: ...](./Chap-01.md)
  - [Chap-02: ...](./Chap-02.md)
  ```
- 각 Chap으로의 마크다운 링크
- 추가 내용 없음 (모두 Chap 파일로 분산)

### 3️⃣ Chapter 파일 (CHAP-NUM.md)
- **상위 링크** (최상단)
  ```markdown
  [← Part N](./PART-N-README.md)
  ```
- 제목: `# CHAP-01 [제목]`
- Chapter 내부 Index (선택사항)
- 세부 강의 내용

## 마크다운 작성 규칙

### 제목 레벨
- `#` - 최상위 제목 (파일 제목)
- `##` - 대분류
- `###` - 중분류 **(순번 규칙: `(1)`, `(2)`, `(3)` ... 형식, `##`마다 리셋)**
- `####` - 소분류
- `#####` - 세부 분류

### Index 규칙
**#, ##, ###을 추가할 때마다:**
1. 내용 먼저 작성
2. Index에 링크 추가
3. 앵커 형식: `[제목](#앵커)`
4. 앵커: 제목을 소문자로, 공백은 `-`, 특수문자 제거

```markdown
## 📑 Index
- [첫째, LLM](#첫째-llm)
- [둘째, Transformer](#둘째-transformer)
```

### 블릿 포인트 규칙
- 상위 항목: `-` 사용
- 하위 항목: `  -` (2칸 들여쓰기) 또는 `####` 사용
- **시각화 우선**: 한 줄보다 여러 블릿

```markdown
- 상위 항목
  - 하위 항목 1
  - 하위 항목 2
```

### 강조 규칙
- 중요 개념: `**볼드**`
- 예제/설명: 일반 텍스트
- 부제목: `####` 사용

## 내용 작성 규칙

### ✅ 필수 규칙
1. **모르는 내용 임의 생성 금지 (사용자 요청 기반 작성)**
   - 강의 영상/자료에 없는 내용 추가 금지
   - 사용자가 직접 제공한 정보만 사용
   - **중요**: 사용자보다 앞서서 가지 말 것
   - 모든 스텝을 사용자의 명시적 요청에 따라 진행
   - PART/CHAP 생성 시: 사용자가 주는 제목 + Index + 상위문서 링크만 사용
   - **CHAP 파일에서 Index 아래의 ### 소제목은 사용자가 명시적으로 제공한 것만 사용** (임의 생성 금지)

2. **어체 규칙**
   - `합니다` 지양
   - 개조식 사용
   - 명사/동사 중심

3. **구조화**
   - 한 줄 설명 지양
   - 여러 블릿으로 시각화
   - 계층적 표현

4. **링크**
   - Chapter 파일: `[제목](./Chap-01.md)`
   - Part Index: `[제목](./PART-1-README.md)`
   - GitHub: `[설명](https://github.com/...)`

### 예시: 좋은 구조

```markdown
### 트랜스포머 아키택처

- Self-Attention 메커니즘
  - 입력의 각 요소가 다른 요소들과의 관계 학습
  - 병렬 처리 가능

- Encoder-Decoder 구조
  - Encoder: 입력 처리
  - Decoder: 출력 생성
```

## Chapter 추가/수정 절차

### 📌 3단계 프로세스

**1단계: 파일 생성 및 기본 구조 작성**
- **파일명**: `Chap-NUM.md` (대문자 C, 하이픈 사용)
- **구조**:
  ```markdown
  [← Part N](./PART-N-README.md)
  
  # CHAP-NUM [사용자 제목]
  
  ## 📑 Index
  - [첫째, ...](#첫째-...)
    - [(1) ...](#1-...)
    - [(2) ...](#2-...)
  - [둘째, ...](#둘째-...)
    - [(1) ...](#1-...)
  - [셋째, ...](#셋째-...)
  
  ## 첫째, [섹션 제목]
  
  ### (1) [소제목]
  
  #### [상세 항목]
  
  ...
  ```
- **세부 규칙**:
  - 상위 링크 추가 (`[← Part N](./PART-N-README.md)`)
  - 제목: `# CHAP-NUM [제목]`
  - ## 레벨: 첫째, 둘째, 셋째... (사용자 요청 기반)
  - ### 레벨: (1), (2), (3)... (순번 규칙, ##마다 리셋)
  - Index 작성 (앵커 포함)
  - **내용은 아직 작성하지 않음**

**2단계: PART README에 연결**
- `PART-N-README.md` 수정
- Index에 해당 Chap 링크 추가
  ```markdown
  - [Chap-05: RAG의 한계를 극복하기 위한 Advanced RAG](./Chap-05.md)
  ```

**3단계: 각 섹션별 단계적 내용 작성**
- 사용자가 강의 자료/내용 제공 → 저자가 마크다운 작성
- 한 섹션씩 진행 (완성 후 다음 섹션)
- 사용자 피드백 → 수정 → 다음 섹션

### 기존 파일 수정 시
- 1단계~2단계는 생략 (이미 파일 및 링크 존재)
- 3단계: 새로운 섹션 추가 (## 또는 ### 추가)
- Index 함께 업데이트
